## 关于我

以编程为工作，主业 Java / Spring Boot 应用开发。习惯通过阅读源码理解框架底层机制，信奉"只有在遇到线上故障后，才能掌握真正的技术"。

## 技能

* **Java 核心**：JDK 源码、并发（CAS、并行流）、动态代理、类加载机制
* **Spring 生态**：Spring / Spring Boot / Spring MVC，深入 IoC、AOP、事务、Bean 容器
* **数据框架**：MyBatis / MyBatis-Plus、JDBC、连接池与分页拦截器
* **数据库**：MySQL（事务、锁、死锁、慢 SQL）；深度阅读 H2 数据库源码（存储引擎、MVCC、MVStore）
* **中间件**：Redis、RabbitMQ、分布式事务（XA/Atomikos）、ShardingJDBC
* **故障排查**：CPU 异常、连接池耗尽、超时、类加载冲突等线上问题定位

自 2016 年起持续记录技术心得，以源码阅读与实战问题为主。
